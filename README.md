# DSC212 – Modularity Assignment

This project explores community detection in complex networks.
The Zachary Karate Club graph is used as the study network.
The network is analysed using modularity-based methods.
The modularity matrix is constructed using Newman’s formulation.
Spectral methods are applied to identify potential communities.
The network is visualised at different stages of the analysis.
Various network properties and centrality measures are calculated.
The results are analysed to understand the community structure.
Python libraries are used for computation and visualisation.
